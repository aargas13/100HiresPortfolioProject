## Steps Completed

1. **Installed Cursor IDE** - Downloaded and installed Cursor from https://cursor.com/

2. **Added the Claude Code add-on** - Opened **Extensions** in Cursor, searched for "Claude Code", installed the extension, and signed in.

3. **Added the Codex add-on** - Opened **Extensions**, searched for "Codex", installed the extension, and signed in.

4. **Created a public GitHub repository** - Logging into GitHub account and created a public repo

5. **Opened the repository in Cursor** - Cloned the repo locally and opened the project folder in Cursor.

6. **Created this README.md** - Documented the tools, steps, and any issues encountered during setup.

7. **Pushing this README.md** - Pushing this .md file to update the repository.
